# fishing_game — Українська браузерна риболовля

Сучасна браузерна гра про риболовлю з автономною роботою офлайн (PWA), процедурним аудіорушієм, динамічним виважуванням та багатим ігровим світом.

## Швидкий запуск
Для запуску просто відкрийте `index.html` у будь-якому сучасному веб-браузері (або запустіть через локальний сервер / додайте як PWA додаток на домашній екран). Збирання чи зовнішні бібліотеки не потрібні.

Прогрес автоматично зберігається в `localStorage` браузера з підтримкою автоматичної міграції старих збережень.

## Основні системи та нові можливості

1. **Повна українська локалізація:**
   - Інтерфейс, назви локацій, спорядження, наживок, крафту, банку та щоденника перекладені українською.
   - Усі 51 вид риби отримали точні українські іхтіологічні назви та атмосферні біологічно-художні описи.
   - Числа форматуються за стандартами локалі `uk-UA`.

2. **Процедурний звук (Web Audio API):**
   - Автономна генерація звуків без завантаження зовнішніх `.mp3` аудіофайлів: закид, сплеск у воді, дзвіночок клювання, тріск котушки, скрип перевантаження снасті, обрив, фанфари трофею, дзвін монет та звук оброблення риби.
   - Регулювання гучності слайдером та кнопка швидкого вимкнення звуку.

3. **Динамічне виважування та стравлювання волосіні:**
   - 3 фази опору риби: спокійна, запекла боротьба та раптові ривки у червону критичну зону.
   - Індикатор напруги волосіні з тактильною вібрацією на мобільних пристроях.
   - Можливість послабити натяг (стравлювання волосіні) клавішею `S` або кнопкою на екрані, щоб уникнути обриву.

4. **Візуальні оновлення Canvas:**
   - Плавна анімація плавання тіні риби під водою біля наживки під час очікування клювання.
   - Анімовані водні сплески та кола при клюванні й витягуванні.
   - Повноцінний цикл зміни дня/ночі (12 хвилин на добу) та погодних явищ (сонячно, дощ, туман, снігопад із плаваючими сніжинками взимку).

5. **Кухня на Базі (Бафи та кулінарія):**
   - Готування страв зі спійманої риби (юшка, смажений судак, щучі котлети, копчений вугор, сашимі тощо).
   - Тимчасові 10-хвилинні посилення: бонус до досвіду, цін на ринку, міцності снастей, шансу трофеїв та швидкості клювання.

6. **Зала слави та досягнення:**
   - 20+ досягнень за дослідження водойм, колекціонування риб, рекордні трофеї, виважування та торгівлю з нагородами у золоті.
   - Персональна зала трофеїв із рекордами та особистими відзнаками.

7. **Керування збереженнями:**
   - Експорт збереження у файл JSON або копіювання в буфер обміну.
   - Імпорт збереження з JSON файлу чи текстового коду.
   - Безпечне скидання прогресу з подвійним підтвердженням.

8. **Стіл оброблення (Розбирання риби):**
   - Чітка кнопка «РОЗБИРАННЯ» з бейджем доступної для очищення риби.
   - Отримання риб'ячого філе, кісток, луски, жиру та морських черепашок (випадають на всіх солоних/морських водоймах).

9. **Мобільний режим та PWA:**
   - Встановлення як прогресивного веб-додатку завдяки `manifest.json` та `sw.js`.
   - Повноекранний режим однією кнопкою (`⛶`).
   - Підтримка сенсорного утримування кнопок та вібро-відгук при клюванні й критичному натягу.

## Завдання, турніри та розвиток бази

- На базі відкрийте **«Завдання та замовлення»**: контракт інспектора, щоденне замовлення ресторану та колекція трьох видів. Ресторан забирає потрібну очищену рибу й доплачує премію; колекція зараховує нові улови без списання риби. Захищені трофеї не використовуються. Завдання оновлюються опівночі за київським часом.
- У **«Умовах ловлі»** оберіть глибину наживки. Таблиця показує бажану глибину, температуру, час доби й наживку кожного виду. Температура води та ці параметри впливають на клювання. Ігрова доба триває 12 хвилин, сезон — 30 хвилин; цикл зберігається між запусками.
- **Турніри** — локальні змагання з трьома комп’ютерними суперниками, без онлайн-сервера. Оберіть найбільшу рибу або загальну вагу; зараховуються тільки улови після вступу та до завершення 10 хвилин. Нагороду можна отримати один раз. Без улову нагорода не видається.
- **Покращення бази** містять причал, майстерню, акваріум, коптильню, склад і кухню. Склад видає наживку один раз на день, кухня відкриває рецепти й підвищує ціну страв. Копчення потребує коптильні.
- У **«Транспорті»** придбайте й екіпіруйте човен, потім вийдіть на глибину. Доступна глибина наживки залежить від човна; з берега — до 12 м. На глибині зростають шанси великих і рідкісних уловів.
- На **кухні** можна приготувати й з’їсти страву для посилення або зберегти її для продажу. Рецепти карася, ляща й морського делікатесу потребують відповідного виду. Готові страви та захищені трофеї зберігаються окремо.
- **Зала трофеїв** містить досягнення, рекорди та фотоальбом із датою, місцем і глибиною. Рекорди фотографуються автоматично; інші улови — кнопкою «Фото» в садку або вікні улову. Картку можна завантажити як PNG; вона залишається після продажу риби. Ліміт — 200 карток.
- **Звуки природи** — процедурні вода, вітер і птахи без зовнішніх аудіофайлів. Звук запускається після першої взаємодії з грою; є окремий перемикач фону та спільна гучність. У прихованій вкладці фон вимикається.
- **Навчання** підказує закид, виважування, оброблення, продаж і покупку. Його можна приховати або повторити з налаштувань.
- **Імпорт** перевіряє JSON і додає відсутні поля старих збережень. Перед заміною створюється резервна копія, доступна для завантаження в налаштуваннях. Помилка файлу чи сховища не замінює живий стан гри. Нові розділи працюють офлайн після першого відкриття через локальний сервер/PWA.

### Перевірка у браузері

Для додаткової перевірки потрібні Playwright і Microsoft Edge. Вони не є залежностями самої гри. Запустіть локальний сервер у корені проєкту:

```sh
python -m http.server 8765 --bind 127.0.0.1
```

В іншому терміналі встановіть Playwright у тимчасову папку та вкажіть шлях до пакета (приклад для PowerShell):

```powershell
npm.cmd install --prefix "$env:TEMP/fishing-game-check" playwright --no-save --no-audit --no-fund
$env:PLAYWRIGHT_PATH = "$env:TEMP/fishing-game-check/node_modules/playwright"
node tests/browser-check.cjs
```

Перевірка використовує окремий профіль браузера, тестує реальний закид, доставку, нагороди, кухню, фото PNG, човни, старі збереження, помилку запису, мобільні вікна та офлайн-запуск.
