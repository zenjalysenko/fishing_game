# fishing_game — Українська браузерна риболовля

Сучасна браузерна гра про риболовлю з автономною роботою офлайн (PWA), процедурним аудіорушієм, динамічним виважуванням та багатим ігровим світом.

## Швидкий запуск
Для запуску просто відкрийте `index.html` у будь-якому сучасному веб-браузері (або запустіть через локальний сервер / додайте як PWA додаток на домашній екран). Збирання чи зовнішні бібліотеки не потрібні.

Прогрес автоматично зберігається в `localStorage` браузера з підтримкою автоматичної міграції старих збережень.

## Основні системи та нові можливості

1. **Повна українська локалізація:**
   - Інтерфейс, назви локацій, спорядження, наживок, крафту, банку та щоденника перекладені українською.
   - Усі 51 вид риби отримали точні українські іхтіологічні назви та атмосферні біологічно-художні описи.
   - Числа форматуються за стандартами локалі `uk-UA`.

2. **Процедурний звук (Web Audio API):**
   - Автономна генерація звуків без завантаження зовнішніх `.mp3` аудіофайлів: закид, сплеск у воді, дзвіночок клювання, тріск котушки, скрип перевантаження снасті, обрив, фанфари трофею, дзвін монет та звук оброблення риби.
   - Регулювання гучності слайдером та кнопка швидкого вимкнення звуку.

3. **Динамічне виважування та стравлювання волосіні:**
   - 3 фази опору риби: спокійна, запекла боротьба та раптові ривки у червону критичну зону.
   - Індикатор напруги волосіні з тактильною вібрацією на мобільних пристроях.
   - Можливість послабити натяг (стравлювання волосіні) клавішею `S` або кнопкою на екрані, щоб уникнути обриву.

4. **Візуальні оновлення Canvas:**
   - Плавна анімація плавання тіні риби під водою біля наживки під час очікування клювання.
   - Анімовані водні сплески та кола при клюванні й витягуванні.
   - Повноцінний цикл зміни дня/ночі (12 хвилин на добу) та погодних явищ (сонячно, дощ, туман, снігопад із плаваючими сніжинками взимку).

5. **Кухня на Базі (Бафи та кулінарія):**
   - Готування страв зі спійманої риби (юшка, смажений судак, щучі котлети, копчений вугор, сашимі тощо).
   - Тимчасові 10-хвилинні посилення: бонус до досвіду, цін на ринку, міцності снастей, шансу трофеїв та швидкості клювання.

6. **Зала слави та досягнення:**
   - 20+ досягнень за дослідження водойм, колекціонування риб, рекордні трофеї, виважування та торгівлю з нагородами у золоті.
   - Персональна зала трофеїв із рекордами та особистими відзнаками.

7. **Керування збереженнями:**
   - Експорт збереження у файл JSON або копіювання в буфер обміну.
   - Імпорт збереження з JSON файлу чи текстового коду.
   - Безпечне скидання прогресу з подвійним підтвердженням.

8. **Стіл оброблення (Розбирання риби):**
   - Чітка кнопка «РОЗБИРАННЯ» з бейджем доступної для очищення риби.
   - Отримання риб'ячого філе, кісток, луски, жиру та морських черепашок (випадають на всіх солоних/морських водоймах).

9. **Мобільний режим та PWA:**
   - Встановлення як прогресивного веб-додатку завдяки `manifest.json` та `sw.js`.
   - Повноекранний режим однією кнопкою (`⛶`).
   - Підтримка сенсорного утримування кнопок та вібро-відгук при клюванні й критичному натягу.

## Тестування та перевірка коду

Для виконання тестів потрібен [Node.js](https://nodejs.org/):

```sh
# Перевірка синтаксису головного скрипту
node --check script.js

# Перевірка поведінкових реакцій риби
node tests/fish-reactions.test.js

# Комплексний тест бази даних, локацій, снастей, кухні та досягнень
node --test tests/game.test.cjs
```
