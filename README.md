# fishing_game

Браузерна гра про риболовлю. Для запуску відкрийте `index.html` у браузері. Прогрес автоматично зберігається в цьому браузері; старі збереження підтримуються.

Куплене спорядження встановлюється одразу. На головному екрані змінюються зображення вудки й поплавка, колір і товщина волосіні, а панель унизу показує всі активні снасті, їхні назви, характеристики та запас наживки. Натисніть потрібну снасть, щоб відкрити її магазин. Раніше куплені котушки можна знову встановлювати без оплати.

Нові можливості:

1. **Щоденний подарунок:** 40–100 монет, 6 порцій хліба та 2 черв’яки. Нагорода зростає за послідовні дні відвідування, до максимуму на сьомий день. Отримання доступне раз на місцеву календарну добу; пропуск дня скидає серію.
2. **Точний закид:** відпустіть кнопку на 66–78% сили, у золотій зоні. Час до клювання скорочується на 25%, успішний улов дає додаткові 15 XP за закид.
3. **Відпускання риби:** у вікні улову або садку можна відпустити нерозібрану рибу за 2–6 очок загальної та місцевої репутації. Рекорд виду залишається в альбомі.
4. **Захищені трофеї:** позначте рибу зірочкою, щоб захистити її від продажу, аукціону, розбирання та відпускання. Повторне натискання знімає захист.
5. **Керування на телефоні та клавіатурою:** утримуйте екранні кнопки «Закинути» й «Підтягнути». На клавіатурі — пробіл для закиду, R для підтягування; на миші — ПКМ і ЛКМ відповідно. Кнопки також підтримують Tab та утримання пробілу або Enter. Відпускання кнопки зберігає прогрес підтягування. Відкриття меню витягує снасть із води.

Перевірки без додаткових залежностей (потрібен Node.js):

```sh
node --check script.js
node --test tests/game.test.cjs
```
